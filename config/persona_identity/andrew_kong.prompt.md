The role line carries two spans, never a pipe: the job title in role-title and the location in role-place. The stylesheet pushes them to opposite edges, so writing "Data Analyst | San Mateo" as one string breaks the layout. Where a role has no recorded location, emit role-place empty rather than omitting the span.

Put filename in <title>:

Andrew_Kong_CompanyName_JobTitle

Replace CompanyName and JobTitle using the target JD.

Do NOT include an external stylesheet <link>. CSS is injected by the host.

Do NOT wrap the HTML in markdown fences.
